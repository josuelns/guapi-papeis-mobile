# guapi-papeis-mobile

> App mobile integrado à API do teste técnico, com formulários validados e fluxo de navegação consistente.

## Problema

App mobile integrado à API do teste técnico, com formulários validados e fluxo de navegação consistente.

## Solução

React Native com Redux Saga para estado assíncrono, React Navigation, NativeWind e validação com React Hook Form + Yup.

## Stack

- React Native
- TypeScript
- Redux Saga
- NativeWind
